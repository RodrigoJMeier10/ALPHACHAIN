# ALPHACHAIN
Blockchain para timestampiar predicciones científicas y colaboración P2P.

## Instalación
python alphachain.py

## Cómo usar
1. Agrega tu predicción: `bc.add_transaction("TuNombre", "Ciencia", 0, "Tu prediccion")`
2. Mina un bloque: `bc.mine_block()`
3. Tu predicción queda inmutable con timestamp
